# Phrasebook design system

The canonical product design guidance lives in `_docs/DESIGN.md`.

- Components: `src/design-system/phrasebook`
- Semantic Tailwind v4 tokens and themes: `src/styles.css`
- Light and dark themes are first-class and persisted locally.
- Product screens use semantic components and tokens rather than raw colors.
- The visual direction is a friendly, tactile learning workspace without borrowed branding, mascots, or proprietary fonts.
